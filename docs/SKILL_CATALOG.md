# Teacher Workbench skill catalog

Release 2.0.0 — 45 skills: one orchestrator and 44 specialists.

| Skill | Purpose |
| --- | --- |
| `tw-orchestrator` | Coordinate a California K–12 teacher-centered instructional support response. Use for broad teaching requests, lesson or assessment projects, teacher-selected curriculum or source access, or work needing several Teacher Workbench specialists; select only the relevant skills and synthesize a cited usable result. |
| `tw-ai-curriculum-integration` | Support optional AI literacy and curriculum integration with current research, verified conditions and independent learning evidence. Use for teacher preparation, unplugged AI learning, demonstrations or approved supervised student AI use. |
| `tw-assessment-design` | Design aligned classroom tests, performance tasks, blueprints, keys and rubrics. Use for formative/summative assessment, scoring design, accessibility review and evidence for intended score interpretations. |
| `tw-behavior-pbis` | Plan positive classroom behavior supports using PBIS, MTSS and relevant SEL or restorative frameworks. Use for expectation matrices, routines, precorrection, participation, feedback, self-monitoring, classroom behavior data, targeted-support planning and team handoffs; ground recommendations in current WWC and primary guidance. |
| `tw-blooms-taxonomy` | Analyze and develop objectives, questions, tasks and assessments using the revised Bloom taxonomy and its cognitive-process and knowledge dimensions. Use for demand audits, task redesign, differentiated questioning, alignment and idea generation; distinguish actual student thinking from verbs, task difficulty, DOK and proficiency levels. |
| `tw-california-curriculum-alignment` | Map California grade/course standards and curriculum frameworks to goals, tasks and evidence. Use for standards lookup, alignment audits, pacing, prerequisite analysis, or a crosswalk for another Teacher Workbench skill. |
| `tw-california-edcode-policy` | Research California Education Code and applicable education policy for a specific school question. Use for current requirements, policy interpretation boundaries, operative dates, or distinguishing statute from guidance and local rules. |
| `tw-canva-production` | Create editable Canva classroom designs from lesson plans, curriculum references or conversation. Use for Canva Docs, worksheets, teaching aids, posters, anchor charts, task cards, reflection sheets and presentations; use an authorized Canva integration when available and label local import-ready fallbacks accurately. |
| `tw-classical-test-theory` | Analyze classroom test scores and items using classical/traditional test theory (CTT). Use for item facility, corrected item-total relationships, distractors, internal consistency, SEM and reproducible response-data audits. |
| `tw-classroom-culture` | Improve classroom routines, participation and belonging through observable evidence and teachable practices. Use for transitions, discussion norms, engagement patterns, restorative conversations and routine instruction. |
| `tw-cross-curricular-assessment` | Design integrated assessments across subjects while preserving each discipline’s standards, criteria and individual evidence. Use for interdisciplinary projects, shared performance tasks, weighting, moderation and separate subject reporting. |
| `tw-cstp-coaching-plc` | Plan developmental coaching, low-inference observation and PLC inquiry grounded in current California Standards for the Teaching Profession. Use for growth goals, coaching conversations, lesson study and evidence reviews. |
| `tw-curriculum-document-intake` | Read and reconcile uploaded or linked scope-and-sequence, pacing, curriculum, unit and lesson-plan documents into a cited planning brief. Use for PDF, Word, presentations, spreadsheets, ebooks, scans/photos, Google documents or conversational notes before lesson, substitute, assessment or material design; preserve sequence, source fidelity and unresolved conflicts. |
| `tw-curriculum-search` | Find and read a teacher's curriculum as a cited reference. Use when the teacher names adopted materials, a curriculum repository, assessment/LMS platform, website, ebook, Google Drive, SharePoint or OneDrive folder; needs guided connection/sign-in, website or folder navigation, edition verification, or a curriculum reference pack for planning, assessments, differentiation or language support. Use available host connectors, browser and file readers; access depends on the user's account and host capabilities. |
| `tw-differentiation-accessibility` | Differentiate California K-12 lessons, materials, participation, and assessments for varied readiness, reading levels, gifted or advanced learners, students with disabilities and documented IEP/504 supports, and multilingual/English learners. Use for scaffolds, accessible task versions, flexible grouping, support and extension pathways, text adaptation, accommodation versus modification decisions, or a differentiation contribution to tw-orchestrator. Preserve the intended learning and provide cited, usable resources. |
| `tw-edtech-integration` | Choose and design educational technology for a specific learning need. Use for tool comparisons, ISTE alignment, TPACK/Triple E analysis, accessibility, implementation planning and technology-failure alternatives. |
| `tw-enrichment-extension` | Design deeper or advanced learning from demonstrated target-specific mastery. Use for curriculum compacting, enrichment, authentic inquiry and challenge for advanced, gifted or twice-exceptional learners. |
| `tw-family-partnership` | Draft reciprocal, accessible teacher–family communication and conference plans grounded in verified classroom facts. Use for progress explanations, invitations, concerns, translations and collaborative follow-up; sending requires explicit authorization. |
| `tw-formative-checks` | Create and interpret brief diagnostic checks, hinge questions and exit tickets that lead to a specific next teaching move. Use for one to three questions, misconception probes, rapid checks for understanding, parallel follow-up items or response-based instructional decisions across subjects. |
| `tw-google-sheets` | Create, format and verify Google Sheets for lesson schedules, scope/sequence maps, assessment trackers, student reflection/progress logs and teacher dashboards. Use a connected Google Workspace/Drive capability when available; otherwise produce an explicitly labeled editable workbook or CSV fallback without claiming a native Google Sheet. |
| `tw-grade-calculations` | Explain, audit and compute complex grade calculations under an explicit local policy. Use for points versus equal assignments, category weights, missing/exempt work, retakes, dropped scores, extra credit, caps/floors, rounding, semester/final blends, GPA scenarios and what-if sensitivity with an auditable calculation trail. |
| `tw-humanities-inquiry` | Design history, social-science and humanities inquiry using authentic sources and evidence-based arguments. Use for source analysis, sourcing/contextualization/corroboration, disciplinary questions and argument rubrics. |
| `tw-instructional-assistant-small-groups` | Create ready-to-run small-group activities for instructional assistants, paraprofessionals, aides or teaching assistants with varied subject knowledge and facilitation experience. Use for assistant-led rotations, guided practice, reteaching, pre-teaching, language groups, intervention or enrichment with scripts, worked keys, scaffolds, response branches and teacher handback so authorized sessions can run without constant teacher presence. |
| `tw-intervention-activities` | Create complete intervention activities from identified skill gaps and learner evidence for Tier 1 core support, Tier 2 supplemental instruction and Tier 3 intensive individualized support. Use for targeted reteaching, prerequisite repair, explicit practice, transfer, intervention adaptations and usable teacher or assistant materials; coordinate ongoing monitoring and team review. |
| `tw-intervention-grouping` | Build flexible intervention groups and feasible schedules from deidentified, target-specific learner evidence. Use for skill-gap grouping, regrouping, multi-need rosters, instructional assistant allocation, Tier 1/2/3 scheduling and coverage audits; return proposals with evidence, constraints, missing-data decisions and review rules. |
| `tw-intervention-progress` | Plan targeted instruction, implementation checks and progress monitoring for a documented learning need. Use for intervention cycles, baseline review, dosage decisions and evidence-informed adjustment within school supports. |
| `tw-item-response-theory` | Explain and plan defensible IRT analysis: Rasch/1PL, 2PL, 3PL and polytomous models. Use for calibration readiness, model/scale choices, information, precision, linking or DIF; decline unsupported parameter estimates. |
| `tw-learning-commons` | Retrieve structured standards, learning components, prerequisite relationships and available curriculum through Learning Commons. Use for Knowledge Graph lookup, curriculum connections, prerequisite maps or connecting the Learning Commons plugin/MCP/API; support authorized local exports when a connection is unavailable. |
| `tw-lesson-rehearsal` | Help a teacher internalize and rehearse an actual lesson. Use for lesson preparation, practicing explanations or questions, anticipating student thinking, simulated classroom dialogue, rehearsal feedback and revising a teaching move before instruction. |
| `tw-lesson-unit-planning` | Create usable California K–12 lessons and units with aligned goals, evidence, models, practice, supports and teacher keys. Use for daily plans, learning sequences, backward design or revising an existing plan. |
| `tw-literacy-instruction` | Plan evidence-informed reading, writing and discussion instruction for California K–12. Use for foundational skills, fluency, comprehension, vocabulary, knowledge-building, writing routines and literacy misconceptions. |
| `tw-marzano-grading-rubrics` | Create and analyze Marzano-style proficiency scales, task rubrics and standards-aligned grading evidence. Use for score 0–4 descriptors, prerequisite/target/extension analysis, rubric exemplars, rating consistency, score interpretation and local grading crosswalks; keep insufficient evidence distinct and honor actual policy. |
| `tw-mathematics-instruction` | Design California mathematics instruction around concepts, procedures, representations and reasoning. Use for worked examples, misconceptions, mathematical discourse, problem sequences and analysis of student methods. |
| `tw-multilingual-instruction` | Plan California K-12 language support and English language development for multilingual/English learners and academic-language needs. Use for content-linked language objectives, integrated or designated ELD, newcomer supports, oral interaction, vocabulary/syntax/discourse scaffolds, bilingual or translated materials, and assessment that distinguishes English proficiency from content understanding. Ground advice in California ELD/content standards, the ELA/ELD Framework, WWC and current research; coordinate with tw-orchestrator or work directly. |
| `tw-pedagogical-review` | Review actual teaching materials against explicit common and subject-specific pedagogical criteria. Use for lesson or assessment quality checks, output evaluations, rubric-based comparisons, checking revisions, and identifying content, alignment, accessibility or evidence problems before classroom use. |
| `tw-pre-post-growth-analysis` | Analyze traditional pre/post assessments and learning growth with matched learners and defensible score interpretations. Use for raw and percentage-point gains, paired summaries, missingness/attrition, effect sizes, confidence intervals, subgroup/standard growth and planning more complex longitudinal or comparison designs. |
| `tw-recurring-workflows` | Prepare and, when supported and requested, schedule recurring teacher planning and evidence-review work. Use for weekly lesson preparation, periodic curriculum updates, repeated deidentified progress reviews, scheduled reminders, or pausing/updating an existing teaching workflow. |
| `tw-research-evidence-review` | Find and appraise instructional research, WWC findings, and current AI studies. Use for research-based advice, conflicting evidence, latest findings, intervention comparisons, or a claim/link audit. |
| `tw-science-instruction` | Plan California NGSS science learning through phenomena, investigation, modeling and evidence-based explanation. Use for three-dimensional alignment, inquiry sequences, data collection and science assessment. |
| `tw-standards-based-grading` | Design, explain and audit standards-based grading policies and evidence decisions. Use for standards/targets, proficiency levels, reassessment, missing evidence, habits versus achievement, reporting conversions, teacher-family explanations and policy comparisons grounded in current California requirements and research. |
| `tw-standards-progress-analysis` | Analyze standards-based evidence over time and across standards, targets and domains. Use for time series, current status, recency/consistency, coverage, standards rollups, mastery transitions, item-standard maps, reassessment patterns, equity/opportunity checks and grading-policy sensitivity analysis with reproducible calculations. |
| `tw-student-reflection-tracking` | Create student-facing reflection, goal-setting, self-monitoring and learning-progress sheets, journals, conference tools or dashboards. Use for academic evidence tracking, plan-monitor-evaluate routines, private behavior reflection, individual growth graphs and student data conversations; separate self-report, completion and demonstrated learning. |
| `tw-student-work-analysis` | Interpret actual deidentified student work against explicit criteria and plan feedback or next instruction. Use for error analysis, work samples, rubric moderation, responsive grouping and evidence gaps. |
| `tw-substitute-planning` | Create operational substitute-teacher packets for single-day, emergency or multi-day absences. Use for uploaded lesson-plan conversion, freeform conversational planning, schedules, explicit teaching directions, printable work, keys, supports, offline alternatives and teacher handback. |
| `tw-teaching-aids` | Create new teacher aids and student-facing resources from a learning goal, uploaded lesson or curriculum reference. Use for anchor charts, worked examples, graphic organizers, manipulatives, task cards, visuals, discussion cards, practice sheets, vocabulary supports and classroom handouts, with separate teacher keys and accessible print or digital layouts. |
