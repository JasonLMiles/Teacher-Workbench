# Use Teacher Workbench in Copilot Cowork

After [installation](copilot-cowork-install.md), start a new conversation. Supply the lesson, rubric, or deidentified evidence through the file picker or an authorized OneDrive source. Request `tw-orchestrator` or a specialist by name.

Cowork displays loaded skills and progress in its side panel and provides built-in tools for Word, Excel, and PowerPoint work. Check the skills used and open the artifacts. See Microsoft's [usage guide](https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/use-cowork).

## Prepare a substitute packet

> Use Teacher Workbench, starting with tw-orchestrator and tw-substitute-planning. Read the attached grade 6 lesson and schedule. Create a one-day substitute packet in Word with times, materials, explicit directions, student work, a separate key, and a handback form. Include a paper option. Flag missing classroom information for me to fill in.

Review the packet, then revise it:

> The substitute cannot access our learning platform. Replace the online activity with an original printable task covering the same objective. Keep the packet within the available time.

## Review evidence and prepare next steps

> Use tw-student-work-analysis and tw-intervention-activities. Review these deidentified exit-ticket responses against the attached rubric. Separate observed errors from possible explanations. Prepare two follow-up activities with examples, student tasks, keys, and checks that tell me when to adjust support.

For a spreadsheet:

> Use tw-grade-calculations. Audit this synthetic gradebook using the attached weighting and missing-work policy. Show inputs, calculations, and exceptions in Excel. Do not change the policy or update a student information system.

## Work with the result

Inspect the output, formula cells, and source links. Ask which calculations were executed and which were reasoned through without a script. Skill instructions do not supply credentials or external curriculum connections.

Keep approved drafts in your normal workflow. Review a family message's facts and tone before deciding how to send it. For recurring preparation, inspect one completed run before requesting a schedule through available host controls.

If a skill is missed, check its installed `tw-` name, start a new conversation, and name it explicitly. Provide an authorized file when a reference is unavailable, or request a result that identifies the evidence gap.
