# Use Teacher Workbench with Google

Complete [installation](google-install.md), then begin with familiar content.

## Start a task

In Gemini Apps with Skills, use `/` or the updated `@` shortcut to select a skill, or request it by name. See [Google's Skills guide](https://support.google.com/gemini/answer/17094296?hl=en). For the Gem adaptation, open your Teacher Workbench Gem and supply the files it needs. In Gemini CLI, launch `gemini` in your teaching-work folder, request `tw-orchestrator`, and review any activation prompt.

## Prepare a lesson

Attach an authorized lesson and ask:

> Use Teacher Workbench to prepare this grade 4 science lesson for 40 minutes. Read the lesson first. Keep its learning goal, include a materials list, explain where students might confuse observation with inference, and make a three-question exit ticket with a separate key. Include language supports that preserve the science thinking. Identify standards that still need verification.

Continue with a concrete correction:

> We have 25 minutes and no student devices. Revise the timing and materials. Keep the learning goal and show which practice you removed.

Request your output:

> Prepare a teacher plan and separate printable student page. If you cannot create a Google Doc here, return clearly separated copy-ready sections.

## Other useful requests

> Use tw-formative-checks. Here are six deidentified responses to my fractions question. Describe evidence of understanding, group observed errors, and propose a ten-minute follow-up with a worked example and key.

> Use tw-instructional-assistant-small-groups. Create a 15-minute activity for four learners. The assistant knows our routine but is new to this content. Include directions, materials, likely errors, and a brief teacher handback.

## Check the result

Confirm the assistant read the material, preserved the objective, checked the key, and distinguished assumptions from facts. Ask which skills and sources it actually used. If retrieval is unavailable, attach an authorized source or request original material with the gap stated.

A Google account alone does not give the assistant tools or permission to write Docs, Sheets, or Classroom content. Verify the actual file or link it returns. Keep work in your approved environment and review the resource before sharing it with students.
