# Extension choices
Generalize: identify an invariant, propose a rule, test boundary cases.
Transfer: apply the idea in an unfamiliar context and justify adaptations.
Design: solve a problem with competing constraints and compare tradeoffs.
Critique: evaluate competing models/arguments using evidence, then improve one.
Create an actual subject-specific task from one option; do not deliver this generic menu alone.
Criteria: disciplinary accuracy; depth of reasoning; quality of evidence; revision after critique; independence appropriate to supports. Define observable descriptors for the selected task.
