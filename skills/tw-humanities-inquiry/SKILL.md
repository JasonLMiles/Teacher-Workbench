# Teacher Workbench Humanities Inquiry

## Start
Read [grounding and citations](references/grounding-and-citations.md) for every invocation. Read [coordination and capabilities](references/coordination.md) for the handoff and host-specific fallback rules. Use the [source directory](references/source-directory.md) to locate relevant authoritative sources; retrieve the actual source before citing its claims. Apply only the foundations relevant to the teacher's decision.

## Inputs
Required: grade/course, topic/question and learning purpose. Optional: supplied sources, perspectives, prior knowledge, reading/language needs, local curriculum and product format.

## Workflow
1. Verify relevant California subject standards and framework guidance. Frame an inquiry question that requires reasoning with evidence rather than recall alone.
2. Retrieve authentic primary and secondary sources with creator, date, context, repository, perspective and permissions. Use a manageable, purposeful set with relevant perspectives; do not manufacture false balance about well-established facts.
3. Inspect what each source can and cannot establish. Design sourcing, contextualization, close reading and corroboration questions. Separate a source's assertion from an established factual claim.
4. Provide language/reading access while preserving provenance and disciplinary reasoning. Label excerpts, paraphrases, translations and invented practice texts accurately. Never fabricate a quotation or present an authored example as a historical primary source.
5. Sequence question → source examination → comparison → tentative claim → argument → revision. Include a teacher evidence map and an analytic rubric for claim, evidence, reasoning and source use.
6. Collect individual reasoning in group inquiry. Check an unfamiliar source or counterevidence to examine transfer and revise the next lesson.

## Deliver
Return a source-based inquiry sequence, authentic verified source list, student organizer, teacher evidence map, argument rubric and an individual check.

## Limits
Do not invent citations, quotations or a consensus. Do not infer a student’s political/religious identity from an argument. Keep assessment on disciplinary evidence and reasoning.

## Routing examples
Direct: “Build an inquiry about California water decisions.” Overlap: science policy assessment → cross-curricular skill preserves both disciplines. Boundary: invented “primary sources” → explicitly labeled fictional practice texts only.
