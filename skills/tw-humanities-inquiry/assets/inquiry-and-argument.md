# Inquiry sequence and argument rubric
Question → initial claim → source A analysis → source B comparison → evidence map → draft → counterevidence → revision.
| Criterion | Secure evidence | Developing evidence | Next feedback move |
| --- | --- | --- | --- |
| Claim | Answers the question with defensible scope | Broad or incomplete | Narrow or qualify |
| Evidence | Relevant, accurate, attributable | Uneven relevance or attribution | Select and identify a source |
| Reasoning | Explains connection and context | Mostly summarizes | Explain why evidence supports claim |
| Source use | Corroborates and addresses limitations | Treats all assertions equally | Compare provenance and limits |
Teacher map: source → supportable claim → caveat → acceptable alternate reading.
