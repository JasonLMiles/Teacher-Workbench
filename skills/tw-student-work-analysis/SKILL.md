# Teacher Workbench Student Work Analysis

## Start
Read [grounding and citations](references/grounding-and-citations.md) for every invocation. Read [coordination and capabilities](references/coordination.md) for the handoff and host-specific fallback rules. Use the [source directory](references/source-directory.md) to locate relevant authoritative sources; retrieve the actual source before citing its claims. Apply only the foundations relevant to the teacher's decision.

## Inputs
Required: actual work/response data and the task; obtain criteria or propose them visibly. Optional: supports, AI conditions, prior teaching, response conditions and student explanation.

## Workflow
1. Inspect the actual artifact, prompt, criteria and administration/support conditions. Confirm what is visible and what is missing. If no work is supplied, provide an analysis template and request a sample; never invent findings about the class.
2. Apply the criteria to specific excerpts or actions. Separate observation, interpretation, alternative explanation and confidence. Missing evidence is not proof of inability; language or transcription can obscure content understanding.
3. Identify useful patterns while preserving exceptions. For a shared product, infer only what the product shows; collect each learner's explanation or transfer task before claiming individual mastery.
4. Offer concise feedback: name evidence tied to the goal, identify one next move, and provide an immediate opportunity to apply it. Do not assign fixed ability labels or diagnose needs from a sample.
5. Plan temporary, target-specific grouping and access/extension routes. Record the next task that could confirm or disconfirm each hypothesis and when to regroup.
6. Use CTT for numerical item/test questions, assessment design for broken tasks/criteria, and multilingual/differentiation support for construct-preserving access. Treat AI detector output as insufficient proof of misconduct.

## Deliver
Return an evidence matrix with specific observations, bounded interpretations, actionable student feedback, revised instruction/grouping and a follow-up check. Cite research for the instructional advice, not for fabricated student facts.

## Limits
Do not infer diagnoses, hidden motives, family background or fixed traits. Use anonymous labels and only needed samples. Do not grade a student solely from a group artifact or an unreliable misconduct inference.

## Routing examples
Direct: “What should I teach next from these exit tickets?” Overlap: numerical quiz review → CTT. Boundary: no samples → a useful protocol and request for evidence, not invented class trends.
