# Teacher Workbench Cross Curricular Assessment

## Start
Read [grounding and citations](references/grounding-and-citations.md) for every invocation. Read [coordination and capabilities](references/coordination.md) for the handoff and host-specific fallback rules. Use the [source directory](references/source-directory.md) to locate relevant authoritative sources; retrieve the actual source before citing its claims. Apply only the foundations relevant to the teacher's decision.

## Inputs
Required: grades/courses, participating subjects, purpose and time. Optional: topic/context, standards, resources, group structure, support/AI conditions and reporting rules.

## Workflow
1. Choose an authentic problem where the disciplines contribute substantively. Verify each subject's standards and define distinct claims about learning. Do not attach unrelated standards to a decorative theme.
2. Fill assets/crosswalk.md: each standard → claim → task component → individual evidence → rubric dimension. Remove or revise claims with no observable evidence.
3. Build one coherent task with clear checkpoints, materials, audience and product. State shared and discipline-specific demands. Include a sample response or teacher solution for each relevant component.
4. Define analytic criteria and explicit weighting/reporting. Keep disciplinary scores visible; explain any composite and why its weights fit the purpose. Do not allow polished writing or design to obscure weak mathematics/science unless communication is itself a target.
5. Plan group work with individual evidence: checkpoint, explanation, process notes or fresh transfer task. Separate content evidence from English proficiency and AI-assisted output from independent learning. Coordinate documented supports without changing the unannounced construct.
6. Moderate sample scoring across teachers and record disagreements/rules. Check workload, timing and meaningful integration. Use multidimensional/descriptive reporting unless a defensible measurement model supports another approach; do not default to unidimensional IRT.

## Deliver
Return the integrated student task, standards/evidence crosswalk, disciplinary rubric with explicit reporting/weights, teacher key/exemplars, individual-evidence plan and moderation protocol.

## Limits
A shared project grade is not evidence that every learner mastered every discipline. Weights are design choices, not validated constants. Preserve non-AI and accessible routes consistent with the teacher’s choices.

## Routing examples
Direct: “Assess science and ratios through a water-use project.” Overlap: language needs → multilingual/differentiation review. Boundary: one shared poster used to claim each member’s mastery → add individual evidence.
