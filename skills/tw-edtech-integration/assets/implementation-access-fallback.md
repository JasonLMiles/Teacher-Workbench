# Technology implementation
Before: verify approval/terms, prepare model and resource, check accessible response options.
During: directions, device/account conditions, interaction routine, evidence capture and teacher monitoring.
After: independent transfer check, learner feedback and workload review.
Access checks: keyboard/assistive use, captions/transcripts, readable contrast/format, language load, home/device access, no unnecessary personal data.
Failure route: same learning goal → available paper/board/material task → equivalent evidence → collection/key.
