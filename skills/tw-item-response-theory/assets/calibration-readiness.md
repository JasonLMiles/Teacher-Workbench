# Calibration readiness
Decision/use / construct(s) / response categories / sampling and administration:
- Item-to-construct map and dimensionality hypothesis.
- Local independence threats (shared passages, chains, testlets).
- Sample and item coverage, sparse categories/extreme patterns, missing design.
- Model/number of parameters and achievable precision; no universal N threshold.
- Identification/scale and estimator; computational resources.
- Convergence, uncertainty, fit/residual and sensitivity plan.
- Group/anchor design if DIF or linking is requested.
- Consequences, fairness, independent validation and limits of intended use.
Decision: proceed with specified model / revise design / CTT description / collect more suitable data.
