# Teacher Workbench California Curriculum Alignment

## Start
Read [grounding and citations](references/grounding-and-citations.md) for every invocation. Read [coordination and capabilities](references/coordination.md) for the handoff and host-specific fallback rules. Use the [source directory](references/source-directory.md) to locate relevant authoritative sources; retrieve the actual source before citing its claims. Apply only the foundations relevant to the teacher's decision.

## Inputs
Required: grade/course, subject, and a task or intended learning. If a code is supplied, verify it. Optional: adopted curriculum, scope/sequence, prior evidence, ELD needs, and time horizon.

## Workflow
1. Identify the applicable California student standards and edition through the CDE portal; locate the official subject PDF if necessary. Read the actual grade/course passage. Verify adoption status and distinguish standards from framework suggestions.
2. Decompose each relevant target into knowledge, disciplinary practice, conditions, and cognitive demand. Paraphrase accurately; quote only a short necessary excerpt. Do not infer an identifier from a neighboring grade or national version.
3. Work backward to observable evidence. Fill assets/standards-crosswalk.md. Mark full, partial, incidental, or absent alignment with a reason; covering a topic alone is insufficient.
4. Compare the actual student task, resource and scoring criteria against the demand. Identify prerequisite knowledge separately from the assessed grade-level target. Check vertical connections only in the actual standards text.
5. Read the relevant framework chapter for instructional implications. Add ELD, arts, computer science, or other standards only when materially addressed. Keep CSTP professional practice in a separate column.
6. Repair the smallest gap: revise the task, add evidence, clarify the criterion, or narrow the alignment claim. Do not add an unsupported list of standards to make a lesson appear comprehensive.

## Deliver
Return a concise verified crosswalk, gaps and concrete revisions, relevant framework implications, and a source record with issuer, edition, grade, identifier and page/section.

## Limits
If official text is inaccessible, label the mapping provisional and provide the task-level analysis without invented codes. Do not call local pacing or a commercial curriculum a state mandate.

## Routing examples
Direct: “Does this grade 7 proportional-reasoning task meet the standard?” Overlap: a new unit → lesson planning after alignment. Boundary: educator evaluation → CSTP coaching; graduation-law requirements → EdCode policy.
