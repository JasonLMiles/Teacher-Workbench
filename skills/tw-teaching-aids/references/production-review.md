# Production review
Check learning first: each element has a purpose; directions state an action; representations preserve the construct; examples/nonexamples and keys are correct; any statistical or scientific graphic uses accurate data and scales.

Check accessibility: clear reading order and headings, readable type, enough response space, contrast, labels beyond color, meaningful image descriptions, nonvisual alternatives where needed, and language demands appropriate to the task. Keep simplification from deleting reasoning or essential vocabulary. Do not claim a formal accessibility certification from a visual pass.

Check classroom use: preparation/assembly burden, copies/materials, expected time, transition between aid and independent work, low-ink option where practical, and separate teacher answers. For a digital artifact test links and controls only through available authorized tools. A PNG/PDF export is a viewable artifact; only claim editability actually provided by the source format or destination app.

Use relevant [CAST UDL guidance](https://udlguidelines.cast.org/) for barriers and options; retrieve the specific consideration at use. A framework is design guidance, not proof that the new aid improves learning. Place claim-specific instructional sources and licensing notes in the teacher companion. Follow the shared current-evidence policy for the learning claim.
