# tw-teaching-aids

Read [grounding and citations](references/grounding-and-citations.md) every time and [coordination](references/coordination.md) when routing work. Verify sources at use; apply only the foundations relevant to this task. Honor teacher AI preferences and preserve documented supports.


## Inputs
Use the goal/construct, grade or reading/language needs, source material, intended use and practical output constraints. Accept conversation or uploaded plans through document intake. Default to an economical printable layout when the medium is unspecified; ask only if format changes the design materially.

## Workflow
1. Define what students must notice, do or explain and how this aid supports it. Choose a form suited to that action: worked model, representation, organizer, comparison, practice, discussion prompt or reference chart. Avoid decorative complexity and worksheet volume without a purpose.
2. Read the selected source or use a clearly labeled original example. Preserve the intended cognitive demand and distinguish authored adaptation from curriculum text. Use the [resource brief](assets/resource-brief.md).
3. Produce the actual aid: exact wording, model/examples, directions, prompts, response space and necessary data/visual content. For manipulatives supply assembly/use instructions; for task cards include numbered tasks and a checked key. Do not merely describe a future handout.
4. Add relevant scaffolds from differentiation/multilingual support: explicit model, chunked prompts, cues, vocabulary, visual representation and graduated independence. Provide extension through depth or transfer. Keep a student-ready version free of teacher-only answers and dense research notes.
5. Use the host's document, presentation, PDF, spreadsheet or image tools for the requested artifact. For Google Sheets route to `tw-google-sheets`; for editable Canva designs route to `tw-canva-production`. Use exact plotting/vector tools for precise mathematics/science diagrams; use available image-generation tools for appropriate illustrative raster art, and verify factual labels separately. Do not claim a native design from a screenshot.
6. Review content/keys, language, source fidelity and accessible layout using [production review](references/production-review.md). Check page breaks, font size, contrast, print margins, image alternatives and actual working space. Supply a low-technology route when needed. Open/render the produced file when a suitable tool exists; disclose unperformed visual checks.

## Deliver
Provide a complete student aid and separate teacher-use note/key, learning target, brief use directions, source/adaptation notes and the requested file or native edit link. Use [student-aid template](assets/student-aid.md) for print resources. Label original resources as proposals, not validated interventions. For a teacher-only reference chart a student worksheet is unnecessary.

## Examples and boundaries
“Turn this lesson into fraction strips and a comparison mat” → accurate scale, actual printable pieces, directions and key. “Create newcomer science vocabulary cards” → meaning-rich examples, visual support and language rehearsal. “Make a poster” with no instructional goal → ask one goal/audience question or state a reasonable design assumption. Do not reproduce a licensed workbook wholesale or add student accounts/AI use without the teacher's choice.
