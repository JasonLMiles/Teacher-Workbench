# Match preparation to the assistant and the task

Use assistant experience as a task-specific input. Subject knowledge, confidence with the routine, language proficiency, familiarity with learners and comfort interpreting responses can differ. Do not infer competence from a job title or years of service. Keep the student learning goal separate from the amount of adult guidance.

| Support mode | Provide | Assistant decisions within the teacher's plan |
| --- | --- | --- |
| Fully scripted: new to this content or routine | Short plain-language concept brief; exact words and demonstrations; defined vocabulary; solved examples; task-by-task acceptable responses; likely errors paired with a checked response; material setup; explicit next-task routes. | Follow named branches, repeat a prepared example, offer specified access supports, use the fallback and record an unresolved question. |
| Guided: familiar with the routine, developing content confidence | Concise run sheet; key questions and rationale; response examples; scaffold choices; pause points; full answer key. | Choose among supplied prompts/examples, adjust wait time and pacing, repeat a specified practice set, or offer the prepared extension. |
| Flexible within scope: secure content and facilitation expertise | Goal and evidence criteria; a compact sequence; task bank and keys; anticipated misconceptions; approved adaptations and boundaries. | Select among aligned tasks, probe reasoning and choose listed scaffold/fading routes while retaining required supports and the target. |

When the teacher has not specified experience, proceed with the fully scripted mode and label that assumption. Generate only the selected mode in full unless parallel versions are requested. For a team with varied experience, provide a common task set/key plus separate run cards; use the same task identifiers and evidence criteria across versions. An assistant may want more support in one subject than another.

## Low-overhead preparation
The design goal is fewer routine interruptions during a defined session. Provide a short written/asynchronous teacher brief and a clear handback; a meeting is not always necessary. Propose a realistic preparation time, not a guarantee that a novice can master a new intervention in a few minutes.

Include a self-check before the group: the assistant rehearses the worked model, checks it against the explanation, and chooses the supplied response to one likely student error. Provide the self-check answers. If still unsure, specify the exact question for the teacher and a fully explained review activity already within the assistant's competence. Do not let an unresolved content question become an improvised explanation for students.

Use teacher-selected curriculum language and representations so group work connects to class instruction. An evidence-based program's training, schedule, dosage, materials and fidelity conditions are not replaced by a generated quick-start card. Mark an altered program as an adaptation and preserve its actual evidence limits.

## Activity architecture
Build a short sequence that fits the supplied period: orient and retrieve relevant prior learning; model when needed; guided practice; each student's application/check; close and record. Change the sequence when the discipline or existing intervention requires it. Protect time for the individual check and transition; do not use every minute for adult explanation.

Use flexible target-specific groups. Base membership or support differences on supplied evidence; if none is available, propose a brief readiness check rather than assigning learner labels. Specify how every student responds while one receives help: write/draw/point privately first, take turns explaining, or compare with a prepared example. Assign roles only when they support learning. Do not use one confident speaker's response as group mastery.

Pre-teaching, retrieval, guided practice, targeted reteaching, oral-language rehearsal, supported inquiry and enrichment are possible activity purposes. State which applies. A new skill can require explicit modeling; do not turn a prompt ladder into a guessing game. A familiar skill can begin with an opportunity to act independently.

For no-print settings write actual board/card/notebook directions, not references to missing worksheets. If the teacher asks for a rotation, include movement, materials reset, noise/participation cues and what the remaining students do. Avoid planning simultaneous duties one adult cannot carry out. Student tasks should not require an assistant to read hidden teacher notes aloud.
