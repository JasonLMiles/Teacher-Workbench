# Spreadsheet production and verification
Use the host's current connector/skill schemas for live calls; this skill packages a workflow, not an OAuth client or standalone API service. Google Drive is the available plugin entrypoint for Docs, Sheets and Slides in some hosts; verify that the selected connection actually exposes creation/editing. Permissions and destination capabilities vary.

The official [Google Sheets create/manage guide](https://developers.google.com/workspace/sheets/api/guides/create) describes creation, returned spreadsheet identity/link and subsequent reading. The [Google Drive file conversion guide](https://developers.google.com/workspace/drive/api/guides/manage-uploads#import_to_google_docs_types) is a starting reference for supported import/conversion. Recheck formats and host support. These documents do not provide user credentials or authorize raw API calls.

For native creation, map the workbook specification to real exposed operations, confirm the selected account/folder, use the requested title, write values/formulas distinctly and obtain returned identifiers. Read actual populated ranges rather than metadata alone when verifying content. Format inputs/calculations clearly, freeze appropriate headers and avoid color-only meanings. Ensure print ranges, table structure and chart labels are meaningful for the requested audience.

For `.xlsx`, use the host's spreadsheet skill and calculation runtime. Check formula syntax and recalculated/cached values when supported; don't claim recalculation if only formula strings were saved. For CSV, preserve UTF-8 and quote cells correctly; treat untrusted text beginning with formula operators as text rather than executing it. Never auto-upload student data to a new external service just to render or convert a workbook.

Sanity checks: a blank observation produces no score, a measured zero stays zero, denominator zero produces a visible blank/status rather than a fabricated percent, totals reconcile, duplicate observations are not double counted, dates sort properly, comparable metrics alone are combined, and an appended record participates in intended summaries. A small meaningful check set is sufficient; do not test every decorative style.
