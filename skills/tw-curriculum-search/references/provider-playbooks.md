# Provider playbooks

These are navigation workflows, not preinstalled connectors. Bind them to the host's actual tools and honor the service's current access controls. Load only the relevant route. Recheck linked provider documentation if implementing an API adapter; the references below do not authorize direct API calls or supply tokens.

| Source | Scope and navigation | Verify before using |
| --- | --- | --- |
| Curriculum repository, GitHub/GitLab or district resource library | Resolve supplied repository/library and path. Use its connected reader or authorized browser. List folders; search titles/objectives within scope; open files and referenced assets. For an explicitly supplied local checkout use `rg --files` and `rg`, then read the files. Do not execute repository code or fetch untrusted dependencies. | Branch/tag/commit or release when exposed; curriculum edition in content; teacher/student variant; actual file path and surrounding context. Use a revision permalink if returned/verified. |
| Assessment system or LMS | Resolve platform, course, grade and curriculum/assessment library. Connect or sign in with the authorized educator account. Use read-only search, folders, filters and item/task preview. Verify that preview is a teacher resource rather than a live student attempt. | Form/version, task/item identifier, standards metadata, administration/scoring notes and restrictions. A bank label is not independent alignment evidence. Keep secure keys in the authorized teacher context and out of student materials. |
| Public website/OER | Start with the supplied publisher/site and course. Use web search/read for discovery and source reading; use an authorized browser for interactive menus, filters or embedded viewers. Follow the actual unit/lesson links. | Publisher, title, edition/update date, stable URL, license and complete relevant text. Check that a sample or marketing page is not mistaken for the full curriculum. |
| Publisher portal or online ebook | Open the specific service after site intent is established. Follow school SSO/sign-in through the approved host flow. Navigate library → title/edition → contents → unit/chapter → lesson/page using observed UI. Search within the book where supported. | Teacher versus student edition, chapter/section and actual page/location, read coverage, access/license limits. Use the authorized reader; do not remove DRM or copy the whole book. |
| Uploaded PDF/EPUB/ebook or exported files | Resolve supplied files through the host file service, then parse/render with available file tools. Read contents/metadata and the relevant sections. Follow associated resources only inside authorized scope. | Title/edition, printed page vs PDF index, EPUB chapter/location, diagrams, OCR accuracy and missing assets. Cite the upload by filename/locator if no verified stable URL exists. |
| Google Drive | Resolve the chosen school account and supplied folder/shared drive. Search scoped title or content; list folder children and follow returned pagination when search misses. Open the actual Docs/Slides/PDF or permitted export. Follow shortcuts only to authorized targets and retain target identity. | File ID and observed web link, parent/folder, modified time/revision when exposed, curriculum edition in the file, native vs exported version, attachments. Do not assume My Drive results cover shared drives. |
| SharePoint/OneDrive | Resolve the supplied tenant/site, document library/drive and folder through the selected Microsoft account. Scope search, list children, follow continuation results, and open the actual document or permitted export. Use the correct SharePoint library or OneDrive location rather than assuming one global drive. | Site/library/drive item identity, observed web link, version/modified time, edition and relevant page/slide/worksheet, permissions and missing attachments. Do not broaden to unrelated tenant content. |
| Other storage services | Discover a relevant connected integration, then use its scoped search/list/read and secure connection workflow. If unavailable, use a permitted website route or authorized upload. | Same identity, edition, locator, coverage and permission checks as above. Do not equate listing access with full content access. |

## Provider references
Opened and checked for identity on 2026-09-29; use current host schemas for actual calls.
- [Google Drive: search files and folders](https://developers.google.com/workspace/drive/api/guides/search-files) describes name/content queries, folder parent filters, identifiers and pagination. Connector search support may be narrower.
- [Microsoft Graph: list folder children](https://learn.microsoft.com/en-us/graph/api/driveitem-list-children?view=graph-rest-1.0) describes folder contents and continuation links.
- [Microsoft Graph: driveItem](https://learn.microsoft.com/en-us/graph/api/resources/driveitem?view=graph-rest-1.0) describes OneDrive and SharePoint file/folder identities and web links.
- [GitHub: navigate repository files](https://docs.github.com/en/repositories/working-with-files/using-files/navigating-code-on-github) describes browsing and finding files in a selected repository.
- [OpenAI: skills and tool boundaries](https://developers.openai.com/plugins/concepts/skills) distinguishes reusable workflow instructions from data, authentication and actions supplied by tools.
