# Lesson output contract — TW-LP 1.2
Use these headings in this order for a complete lesson by default. Fill every section; write a concise “not applicable” with reason when appropriate rather than silently dropping it. For a narrow edit, return only the requested section. The sequence is a consistent reporting format, not a mandate to use every teaching phase.

1. Overview — title, grade/course, subjects, duration, date/window if supplied and curriculum edition.
2. Sources and alignment — source IDs/locators, verified content standards/framework passages, supplied unverified codes labeled, and prior/next sequence links.
3. Learning goals and success criteria — student-friendly target, separate language objective where relevant and evidence needed.
4. Preparation and prerequisites — materials, actual source pages, preparation, readiness check and technology/offline conditions.
5. Lesson sequence — table columns: Time/minutes; Teacher moves/model; Student task; Evidence/check; Response/next step. Totals must fit the lesson and tasks must be fully written or attached.
6. Scaffolds, language supports and extension — barrier/need, actual support, construct effect, evidence to adjust/fade temporary support, required accommodations preserved, advanced challenge.
7. Assessment and next instruction — formative/exit task, scoring or success criteria, independent evidence and proposed response rule.
8. Student materials — complete handouts/tasks, ready to use; separate printable sections/files when useful.
9. Teacher key and use notes — worked answers, criteria, likely misconceptions and implementation notes; not on student pages.
10. Reflection, sources and changes — what teacher checks next, claim-specific research citations, assumptions, changes from supplied plan and version/date.

When the teacher uploads a required template, preserve its headings and order. Map these ten components to that format using a short teacher note; include missing essential information in an appendix. Do not force the default layout over a district-required format or invent district mandates. For units use the unit-plan template plus this contract for requested detailed lessons. For conversations build an initial version from known facts, then maintain the same structure and show material revisions as details change.
