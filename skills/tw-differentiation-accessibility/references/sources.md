# Differentiation source index
Baseline checked 2026-09-28. Follow the shared policy: verify the specific source and claim at use, and search for newer relevant research. Do not treat this index as a complete evidence review.

| Source | Use and limits |
| --- | --- |
| [CAST UDL Guidelines](https://udlguidelines.cast.org/) | Retrieved official version 3.0. Select relevant considerations; distinguish framework guidance from evidence for a particular intervention. |
| [California standards](https://www2.cde.ca.gov/cacs/) | Retrieve the actual subject/grade standard before naming an identifier. |
| [CDE ELA/ELD Framework chapter 5](https://www.cde.ca.gov/ci/rl/cf/documents/elaeldfwchapter5.pdf) | Official PDF retrieved. This chapter addresses grades four and five only. Use the corresponding chapter for another grade. |
| [CDE framework index](https://www.cde.ca.gov/ci/cr/cf/allfwks.asp) | Official location; direct automated index retrieval was blocked during the specification review. Retrieve the relevant official PDF or teacher-provided copy instead. |
| [WWC foundational reading guide](https://ies.ed.gov/ncee/wwc/PracticeGuide/21) | K–3 instructional evidence; inspect relevant recommendations and their ratings. Do not generalize automatically to older readers. |
| [WWC reading intervention guide](https://ies.ed.gov/ncee/wwc/practiceguide/29) | Grades 4–9; use for an identified reading need rather than interpreting one reading score as a full profile. |
| [WWC English learner guide](https://ies.ed.gov/ncee/WWC/PracticeGuide/19) | Elementary/middle school scope. Inspect the exact recommendation and its evidence level. |
| [National Center for Research on Gifted Education](https://ncrge.uconn.edu/resources/) | Research discovery point for advanced learning and acceleration. Retrieve a specific study before making an effect claim; a project description is not an outcome study. |
| [Testing Standards](https://www.testingstandards.net/open-access-files.html) | Official access point for the published testing standards. Consult relevant validity, accessibility, and score-interpretation guidance. |

Use current research for the actual proposed practice, including null or conflicting findings. For an AI-generated adaptation, inspect current AI evidence and the exact output; do not infer learning benefit from faster content production.
